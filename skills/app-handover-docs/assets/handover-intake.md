## 给交接方的提问话术（可直接复制发送）

> 你好，我正在接手 XXX 系统，需要整理一套完整的交接文档。麻烦协助提供以下信息：
>
> 1. 系统的 Git 仓库地址，以及是否有历史交接文档 / 设计文档 / 接口文档（Swagger 地址）
> 2. 生产环境的部署信息：几台机器、部署方式、有没有 K8s / Docker 编排文件
> 3. 有哪些**坑**：容易出问题的地方、历史上出过的事故、有没有不能碰的老代码
> 4. 日常运维由谁负责，出问题应该找谁，有没有现成的告警群 / 值班表
> 5. 有没有**只能口头说、没写在文档里**的约定（比如某张表要手工刷、某个任务不能白天跑）
>
> 第 3、5 条尤其重要——这两条是文档里最有价值、也最容易在代码里看不到的部分。
